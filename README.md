# LMS研修システム（助成金受給対応モデル）

厚生労働省「人材開発支援助成金」対応の教育訓練プラットフォーム。
受講ログ（日時・時間・進捗）を秒単位で管理・証明することを主目的とする。

## セットアップ

```bash
# 仮想環境（推奨）
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate    # macOS/Linux

# 依存パッケージ
pip install -r requirements.txt
```

## 起動

### 開発（デバッグ）
```bash
python app.py
# http://127.0.0.1:5000
```

### 本番（waitress WSGIサーバ）
```bash
python serve.py
# http://0.0.0.0:8080
```

初回起動時に管理者アカウント（`admin`）が作成され、初回ログイン時にパスワード変更が強制される。

## 環境変数（本番では設定推奨）

| 変数 | 説明 | 既定 |
|---|---|---|
| `LMS_SECRET_KEY` | セッション秘密鍵。**本番では必須**（未設定だと再起動で全ログアウト） | 起動ごとにランダム |
| `LMS_ADMIN_PASSWORD` | 初期管理者パスワード（初回変更強制） | `admin123` |
| `LMS_HTTPS` | `1` でCookieのSecure属性を有効化（HTTPS配信時） | 無効 |
| `LMS_HOST` / `LMS_PORT` | 待受ホスト/ポート | `0.0.0.0` / `8080` |
| `FLASK_DEBUG` | `1` で開発デバッグモード（本番では設定しない） | 無効 |

Windows での設定例（PowerShell）:
```powershell
$env:LMS_SECRET_KEY = "（openssl rand -hex 32 等で生成した長い文字列）"
$env:LMS_ADMIN_PASSWORD = "（初期パスワード）"
python serve.py
```

## データベースのマイグレーション

既存DBに列/テーブルを追加した場合はマイグレーションを実行する（データは保持される）:

```bash
python migrate.py
```

## バックアップ（法定保存期間5年）

```bash
python backup.py
```

DBコピーと全ログCSVを出力し、5年より古いバックアップを自動削除する。
Windowsタスクスケジューラでの定期自動実行手順は `BACKUP_SCHEDULE.md` を参照。

## データベースについて（SQLite継続の判断）

本システムは SQLite（`instance/lms.db`）を使用。

- **小〜中規模（同時受講者が数十名程度まで）**: SQLite で問題なし。書き込みは短時間で完了し、
  ログ追記・進捗更新のワークロードは軽量。導入・バックアップも単純（ファイルコピー）。
- **大規模・多数同時書き込みが想定される場合**: SQLite は書き込み時にDB全体をロックするため、
  PostgreSQL 等への移行を検討する。移行時は `app.py` の
  `SQLALCHEMY_DATABASE_URI` を変更する（ORM層は共通のため大きな改修は不要）。

現状の受講規模では SQLite 継続で差し支えない。

## 既知の制約と運用上の判断

- **動画本体の保護**: 動画は YouTube に配置し、受講画面には動画IDのみをAPI経由で渡している。
  YouTube の限定公開（Unlisted）を利用してもURL/IDが漏れれば受講画面外から視聴は可能。
  ただし助成金審査の要点は「視聴時間の記録・証明」であり、視聴時間はサーバ側の実時間ハートビートで
  計上している（クライアント申告値ではない）ため、LMS外視聴では学習時間として計上されない＝
  修了要件を満たせない設計になっている。運用上は限定公開動画の使用を推奨する。
- **コンテンツ制御（倍速・シーク・タブ切替）**: ブラウザJSによる制御のため、技術者は開発者ツール等で
  回避しうる。ただし回避しても視聴時間はサーバ側の実時間ベースで計上されるため、
  時間の水増しにはつながらない。

## 主要な助成金対応機能

- ログイン/ログアウト証跡の秒単位記録（管理画面 → 受講ログ → ログイン証跡CSV）
- 学習進捗・実視聴時間の記録（改ざん防止: サーバ実時間ベースで加算、動画長で上限化）
- 未視聴制御（前チャプター完了まで次レッスンに進めない）
- 倍速・シーク・タブ切替の制限（受講中画面）
- 理解度テスト（合格点制御・解答履歴保存）
- 受講証明書PDF・受講ログCSVの発行
